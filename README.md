# 📝 AI Todo List App

A full-stack Todo List application with AI integration.

## 🚀 Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express
- OpenAI API

## 📂 Project Structure

F&B/
│
├── backend/
│   ├── server.js
│   └── package.json
│
└── frontend/
    ├── index.html
    ├── style.css
    └── script.js

## 🔧 Installation (Backend)

1. Clone the repository
2. Go to backend folder: F&B/backend/
3. Install dependencies: npm instsall
4. Create a `.env` file: API KEY OPENAI
5. Start the server: npm run start


## 🌍 Deployment

- Frontend: Netlify
- Backend: Render

## ⚠️ Important

The OpenAI API key is stored securely using environment variables.
It is NOT included in this repository.
